# yugomee.github.io

Personal homepage of **Jihyun Yu (유지현)** — Ph.D. student in Artificial Intelligence at Ewha Womans University, [Practical AI Lab](https://pai.ewha.ac.kr/).

🔗 **https://yugomee.github.io**

## About

A single-page academic homepage: about, news, publications, experience, and education. Built with plain HTML/CSS/JS — no frameworks, no build step.

- `index.html` — main page
- `publications.js` — publication list (one object per paper; arXiv/Code/PDF buttons render automatically)
- `style.css` — minimal academic theme with dark-mode support

There may or may not be a hidden page. The cats know. 🐾
